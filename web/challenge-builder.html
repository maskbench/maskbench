Dataset mounted & MASKBENCH_DATASET_DIR set
resolves to /datasets in container
why it bitesOn a cluster the bind-mount is the #1 silent failure. In .env set MASKBENCH_DATASET_DIR=/scratch/$USER/videos; docker-compose maps it to /datasets. With enroot/pyxis use --container-mounts instead — see enroot_scripts/.
Model weights present in /weights/pre_built
pose_landmarker_heavy.task + hand_landmarker.task
why it bitesThe Dockerfile pulls from .../latest/ URLs with no checksum, so two builds can ship different weights. Pin the version and record its hash here so the release is reproducible — participants need to know exactly which model produced the landmarks.
All filenames follow the convention
CORPUS_speaker_clip_category[_subtype]
why it bitesA name with too few parts, or missing the gesture/nogesture token, returns None from the parser and the clip is dropped (or crashes rendering). 3 files were skipped on this run — rename them before release or they vanish from the dataset silently.
Output directory is writable
checkpoint + permissions on shared FS
why it bitesThe container runs as root and entrypoint.sh does chmod -R a+rw /output — on a shared cluster FS that can fail or leave files you can't delete. Point MASKBENCH_OUTPUT_DIR at scratch you own.
Reviewed the 6 missing-output videos
input → output reconciliation above
why it bitesPer-video exceptions are caught and logged, then processing continues — so a crash looks like success. Always reconcile counts: 1,204 in → 1,198 npz. The 6 gaps are usually ragged arrays from frames with no detection. Check the run log.
GPU / enroot allocation confirmed
interactive vs batch (srun / sbatch)
why it bitesMediaPipe falls back to CPU silently if no GPU is visible — a 1,200-video run then takes hours. Verify the device inside the container, and for batch use the scripts in enroot_scripts/ rather than an interactive docker compose up.

Mirror pairs
148 mirror pairs kept in the same split
why it bitesA clip flagged is_mirror is an augmentation of an original. If the original lands in train and its mirror in test, the model has effectively seen the test clip — silent leakage that inflates scores. Grouping pins both to the same side.
Mirrors grouped with their speaker
Per-corpus coverage
All 7 corpora present in both splits
why it bitesIf the test set is dominated by one corpus, a model can score well by learning corpus shortcuts (camera, lighting, language) instead of gesture. Stratifying by corpus keeps the benchmark measuring what you intend.
SaGA: only 4 test speakers — thin coverage
